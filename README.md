# Site Institucional — Instituto Poder Social

Site estático responsivo, sem dependências externas, pronto para hospedagem em Vercel, Netlify, GitHub Pages, Cloudflare Pages ou servidor convencional.

## Estrutura
- `index.html` — home
- `institucional.html` — identidade institucional
- `atuacao.html` — eixos e metodologia
- `projetos.html` — portfólio de projetos
- `transparencia.html` — governança e documentos
- `noticias.html` — comunicação institucional
- `contato.html` — contato
- `privacidade.html` — base de política de privacidade
- `acessibilidade.html` — declaração de acessibilidade

## Pontos antes de publicar
1. Validar estatuto, CNPJ, diretoria e documentos oficiais.
2. Inserir certidões reais e relatórios oficiais na área de Transparência.
3. Conectar o formulário a um serviço de envio (CRM, e-mail, Supabase, Formspree etc.).
4. Revisar política de privacidade e LGPD com responsável jurídico.
5. Conectar Notícias a CMS, se desejado.

## Identidade
Cores principais: azul-marinho, turquesa, branco e tons gelo, em continuidade com o portfólio institucional.
